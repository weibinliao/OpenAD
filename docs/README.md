## 语言约定

当前治理、开发、维护和用户入口文档采用中文完整正文在前、英文对应内容在后的双语格式。历史里程碑和清理记录可以保留中文原文并附英文摘要。命令、路径、代码标识、协议字段和兼容文件名保留英文。

历史文档如存在能力夸大，以根目录 README、功能矩阵和当前源码为准。

### Language Convention

Current governance, development, maintenance, and user-entry documents place complete Chinese content first and corresponding English content second. Historical milestones and cleanup records may preserve the Chinese original with an English summary. Commands, paths, identifiers, protocol fields, and compatibility filenames remain in English.

When historical documents overstate a capability, the root README, feature matrix, and current source code take precedence.
