# ADR 0000：决策标题

[中文](#adr-0000决策标题) | [English](#adr-0000-decision-title)

- 状态：提议
- 日期：YYYY-MM-DD
- 负责人：项目维护者

## 背景

描述需要作出决策的问题、约束和客观事实。

## 决策

准确说明选择的方案，包括模块边界和兼容范围。

## 影响

列出运维、开发、安全、数据和迁移方面的影响。

## 备选方案

列出合理备选方案以及未采用的原因。

## 验证

列出证明决策已正确实现所需的测试、构建、迁移、运行检查或文档。

## ADR 0000: Decision Title

- Status: Proposed
- Date: YYYY-MM-DD
- Owner: Project maintainers

### Context

Describe the problem, constraints, and objective facts that require a decision.

### Decision

State the selected approach precisely, including module boundaries and compatibility scope.

### Consequences

List operational, development, security, data, and migration effects.

### Alternatives

List reasonable alternatives and why they were not selected.

### Verification

List tests, builds, migrations, runtime checks, or documentation required to prove the decision is implemented correctly.
